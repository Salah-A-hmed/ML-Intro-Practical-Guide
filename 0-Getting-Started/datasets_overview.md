# Datasets Overview

هذا الملف يشرح جميع الـ Datasets الموجودة في الريبو:

- iris_dataset.csv → Logical Models (Decision Tree)
- weather_play.csv → Rule-Based Example
- hours_scores.csv → Linear Regression Example
- synthetic_points.csv → KNN Example
- tennis_dataset.csv → Naive Bayes
- clustering_data.csv → K-means (Only two types: age, income)
- gridworld.txt → Reinforcement Learning grid
