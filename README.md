# Machine Learning – Intro Practical Guide

### A beginner-friendly practical companion to understanding ML basics

هذا الريبو مصمّم ليكون دليل عملي بسيط لأي شخص يبدأ تعلم أساسيات **Machine Learning**.
هو مبني خصيصًا ليُكمل الجزء النظري الموجود في أول 15 صفحة من كتاب المادة، بحيث يتحول الكلام النظري لأمثلة حية يمكن تجربتها فورًا بدون أي تعقيد.

الريبو يحتوي على:

* أمثلة عملية لكل نوع من نماذج التعلم المذكورة في الجزء النظري
* Datasets صغيرة جاهزة للاستخدام
* Jupyter Notebooks جاهزة بالشرح والكود
* خطوات تشغيل بسيطة لأي مبتدئ
* Visualizations تساعد في فهم المفاهيم بسرعة
* ترتيب منطقي يمشي مع البريزنتيشن والفيديو

---

## محتويات الريبو

### **0 – Getting Started**

يحتوي على:

* طريقة تثبيت Python & Libraries
* كيفية فتح وتشغيل الـ Notebooks
* نظرة عامة على جميع الداتا سيتس الموجودة في الريبو

### **1 – Logical Models**

هنا بنطبق أبسط نماذج Machine Learning:

* Decision Trees
* Rule-Based Systems

أمثلة:

* شجرة قرار باستخدام Iris dataset
* Model بسيط باستخدام IF-THEN rules على Weather dataset

---

### **2 – Geometric Models**

#### **2.1 – Linear Models**

* تطبيق Linear Regression
* Animation لخط الانحدار وهو يعمل Fit باستخدام Gradient Descent

#### **2.2 – Distance-Based Models**

* مثال على K-Nearest Neighbors
* Dataset بسيط في بعدين فقط لتوضيح الفكرة

---

### **3 – Probabilistic Models**

تطبيق مباشر على:

* Naive Bayes
  باستخدام Tennis Dataset

---

### **4 – Types of Learning**

نطبّق الأنواع الثلاثة:

* Supervised Learning → Classification Example
* Unsupervised → K-means Clustering

### **5 – Design Learning System** 

* خطوات تصميم نظام تعلم آلي من الصفر
* شرح عملية اختيار البيانات، الخصائص (Features)، والنماذج
* كيفية تقييم النظام وتحسين الأداء

* دليل كامل للمبتدئين لتطبيق دورة حياة **Machine Learning** على بيانات مبيعات حقيقية
